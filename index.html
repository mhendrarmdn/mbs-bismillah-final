VERIFIED FROM HAR

State-transition validation: Backtest R2–R8 reproduces cash within ~$302 max error, ending equity within ~$373, and pre-tax profit within ~$631. R1 is excluded because the opening-state inventory treatment is special.

These reproduce observed Simulation 1 values.

Equipment fee = Investment² / 10,000,000

BVₜ = BVₜ₋₁ − floor(2.5% × BVₜ₋₁) + Investmentₜ

Next Capacity = floor(Capacity × 0.975) + floor(Investment / (20 × Current Price Index))

Replacement Cost = Next Capacity × 20 × Next Price Index

Economic Equity = Owner's Equity − Equipment BV + Replacement Cost

Actual Dividend = min(Proposed, max(0, Beginning Equity − Equity Floor))

Progressive tax (Low / Moderate / High): 0–200k, 200–500k, 500k–1m, >1m marginal brackets

Management Expense = (150,000 + 0.32 × Capacity [+ 50,000 if overtime]) × Price Index

Misc Expense = (10,000 + 0.18 × Capacity) × Price Index

Inventory COGS adjustment = Beginning FGI value − Ending FGI value

Ending FGI unit value = 3 × Current Price Index; FG holding cost = Ending FGI value / 6

RM holding cost = 5% × Beginning RM inventory value
